# Mi Proyecto SvelteKit

Un proyecto web desarrollado con SvelteKit.

## Requisitos

* Node.js (versión 24.21.0 LTS recomendada)
* pnpm (versión 12)

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Joe-D-Fer/EcoConsumo
   cd EcoConsumo
   ```

2. Instala las dependencias:
   ```bash
   pnpm install
   ```

## Desarrollo

Inicia el servidor de desarrollo y abre la aplicación en tu navegador:

```bash
pnpm run dev --open
```

## Producción

Para compilar la aplicación para producción:

```bash
pnpm run build
```

Puedes previsualizar la compilación con:

```bash
pnpm run preview
```
